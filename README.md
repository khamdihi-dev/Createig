# Nexora

> Web-based Instagram Account Automation Dashboard

![Poster](https://github.com/khamdihi-dev/Createig/blob/main/img/poster-create-ig.jpeg)

## 🚀 Overview

**Nexora** adalah tools berbasis web untuk membuat akun Instagram secara otomatis dengan tampilan modern, cepat, dan terstruktur.

Cocok untuk kebutuhan automation, testing, digital marketing, dan manajemen akun Instagram.

---

## ✨ Features

- ⚡ Bulk Instagram Account Create
- 📊 Progress Real-time
- 📁 Hasil Akun Terorganisir
- 📋 Salin Semua Hasil Sekali Klik
- ✅ IG Checker
- 🗂 Remove File Manager
- 🎨 Modern Dashboard UI
- 📱 Responsive Design

---

## 🖥 Dashboard Preview

### Create Account
- Input cookie/session
- Set jumlah akun
- Progress otomatis realtime

### Hasil
- Menampilkan akun yang berhasil dibuat
- Salin semua hasil dengan satu klik

### Remove File
- Menghapus file hasil dengan mudah

### IG Checker
- Mengecek status akun Instagram
